An immersive, state-of-the-art devotional web sanctum celebrating **Lord Shri Krishna** and **Srimati Radharani**. This application unites ancient Vedic spirituality with cutting-edge full-stack web engineering, featuring physics-driven particle animations, 3D typography depth layering, procedural audio synthesis, bilingual chronicles of 50 sacred Leelas, and frosted glass UI aesthetics.

---

## 🌟 Key Features & Highlights

### 🏺 1. Interactive Dahi Handi & Spinning Flute Intro Experience
* **Harmonic Pendulum Sway**: Hanging earthen pot swings dynamically in a smooth gravitational arc with curd droplets sloshing at peak turnaround points.
* **Flute Smash & Particle Explosion**: Tapping or clicking the pot sends Lord Krishna's golden Bansuri swooping across the screen to smash the handi.
* **Multilayered Physics FX**: Realistic porcelain fracture shards, drifting peacock plumes, fluttering marigold petals, and an explosive curd fountain burst.
* **Procedural Sound Synthesis**: Built with the **Web Audio API**—generating ceramic collision crackles, flute aerodynamic swooshes, splash impacts, and resonant temple bells without relying on external sound assets.
* **Fluid Curd Drain Physics**: Viscous fluid surface tension, deceleration friction, and trailing rivulets that realistically pour down and drain out of the viewport.

### 🌌 2. 3D Depth Typography & Divine Hands Hero Stage
* **Layered Visual Depth**: Atmospheric starry cosmic video background layered behind massive *Cinzel* typography (`RADHA KRISHNA`), with high-resolution divine hands holding the holy flute rendered in the foreground *over* the text.
* **Directional Elastic Nav Pill**: Navigation bar indicator that stretches directionally based on hover/click direction with organic elastic recoil.
* **Interactive Spotlight Beam**: Dynamic mouse-tracking illumination that highlights cosmic dust and peacock feathers on the canvas.
* **Background Atmosphere Switch**: One-click glass toggle to transition between ambient video celestial motion and OLED pure black mode.

### 📜 3. Transcendental Leelas Archive (50 Illustrated Pastimes)
* **Complete 50 Pastime Chronicles**: Spanning six sacred chapter epochs:
  1. **बाल व गोकुल लीला (Gokul & Bal Pastimes)** — *Leelas 1 to 10*
  2. **वृंदावन व सखा लीला (Vrindavan & Cowherd Friends)** — *Leelas 11 to 22*
  3. **रास व निकुंज लीला (Raas & Nikunj Pastimes)** — *Leelas 23 to 28*
  4. **मथुरा व कंस लीला (Mathura & Deliverance of Kansa)** — *Leelas 29 to 35*
  5. **द्वारकाधीश लीला (Dwarkadhish Pastimes)** — *Leelas 36 to 43*
  6. **महाभारत व गीता लीला (Mahabharata & Gita Wisdom)** — *Leelas 44 to 50*
* **Bilingual Invocations**: Fully written in authentic **Hindi (Devanagari)** and **English**.
* **Handcrafted SVG Illustrations**: 50 unique vector emblems meticulously designed for each pastime with custom gradients and halos.
* **Live Search & Instant Filtering**: Real-time fuzzy query filtering across all 50 pastimes, categories, and Sanskrit keywords.

### 🛕 4. Temple Darshan & Sacred Teachings
* **Sanctum Showcases**: Dedicated virtual darshans for Banke Bihari (Vrindavan), Radha Rani Palace (Barsana), Krishna Janmabhoomi (Mathura), and Jagat Mandir (Dwarka).
* **Bhagavad Gita Wisdom & Mantras**: Authentic Sanskrit shlokas, English translations, and one-tap Maha-Mantra copy functionality.
* **Sacred Chants Modal**: Comprehensive devotional prayer repository containing the Maha-Mantra, Radha Gayatri Mantra, and Gita verses.

### 🎵 5. Divine Flute Harmony & Sudarshan Chakra Controller
* **Continuous Ambient Bansuri Player**: Seamless looping transcendental flute melody.
* **Rotating Sudarshan Chakra Button**: Bespoke 24-spoke flaming chakra with golden rim gradients that spins dynamically while sacred melodies play.

### 🪶 6. Custom Devotional Peacock Cursor
* **Peacock Feather Quill**: High-fidelity angled peacock quill pointer with a luminous writing tip.
* **Context-Aware Dot Transform**: Smoothly morphs into a pristine glowing white dot cursor when hovering over interactive text, buttons, and cards.

## 🚀 Getting Started

No build tools, bundlers, or package installations are required! This project runs entirely on native web standards.

### Option A: Open Directly in Browser
1. Clone this repository or download the ZIP:
   ```bash
   git clone https://github.com/kishan-src/KR-NA.git
   ```
2. Navigate to the project directory:
   ```bash
   cd KR-NA
   ```
3. Double-click `index.html` to launch it directly in your favorite modern browser (Chrome, Edge, Firefox, Safari, Brave).

### Option B: Run with VS Code Live Server (Recommended)
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension by Ritwick Dey.
3. Right-click `index.html` and click **"Open with Live Server"** (or press `Alt + L, Alt + O`).
4. The site will launch automatically at `http://127.0.0.1:5500/index.html`.

### Option C: Run with Python HTTP Server
```bash
# Python 3.x
python -m http.server 8000
```
Open your browser and navigate to `http://localhost:8000`.

## 🛠️ Technology Stack & Performance

* **HTML5**: Semantic elements (`<main>`, `<article>`, `<section>`, `<nav>`, `<aside>`, `<header>`).
* **CSS3**: Native CSS custom properties (variables), Flexbox, CSS Grid, 3D transforms, keyframe animations, glassmorphism backdrop filters.
* **Vanilla JavaScript (ES6+)**:
  * Event delegation, IntersectionObserver, and URL hash routing.
  * Web Audio API synthesized procedural sound effects.
  * Zero third-party npm runtime dependencies for near-instant 60 FPS loading.
* **Vector Graphics**: Over 50 inline SVG artworks optimized for high-DPI and retina displays.
